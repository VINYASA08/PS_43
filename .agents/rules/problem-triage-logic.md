# Triage Tracks
When developing database schemas, AI categorization logic, or routing workflows in this project, you must enforce the following three tracks for all submitted problems:

1. **Track A (Innovation/Complex):** 
   - Criteria: Requires research, novel solutions, or multi-disciplinary approaches.
   - Routing: University Research Dashboard + Industry Mentorship.
   - Purpose: Fulfills NEP 2020 experiential learning mandates.

2. **Track B (Standard/Routine):**
   - Criteria: Routine engineering or development tasks (e.g., building a standard inventory app for an NGO).
   - Routing: University Student Dashboard (for capstones/micro-credits). No Industry Mentorship required.
   - Purpose: Practical skill application.

3. **Track C (Civic/Out-of-Scope):**
   - Criteria: Basic municipal complaints (e.g., broken streetlights, potholes).
   - Routing: Forwarded directly to Government/Municipal bodies. Kept out of the student innovation pool.
