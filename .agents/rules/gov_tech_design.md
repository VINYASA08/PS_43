# Government Tech Design Principles (Zero-Negative Model)

When designing or building features for government, civic, or public sector technology platforms, you must strictly adhere to the following "Zero-Negative" principles to ensure ground-level success:

1. **Bridge the Digital Divide (Omnichannel Intake)**: Never assume users have high digital literacy or high-speed internet. Always design alternative intake methods (e.g., WhatsApp chatbots, SMS, IVRS, or Common Service Center kiosks) alongside standard web forms.
2. **Prevent Superficial Disposal (Citizen Verification)**: Ensure that government officials or assigned agencies cannot unilaterally close a ticket or grievance. The workflow must include a "Citizen Verification Gate" where the original reporter validates the resolution.
3. **Enforce Bureaucratic Accountability**: Always implement public transparency features, such as a Public Accountability Index (ranking departments by SLA compliance) and visual Auto-Escalation triggers for stalled tasks.

Always review these principles before creating an implementation plan for a civic tech project.
